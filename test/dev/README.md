# Development scratch scripts

Kept for reference; not part of the test suites. Each loads the physics
modules through `../load.js` and prints a trace: `hover.js` (trimmed hover),
`gov.js` (governor step), `disc.js` (isolated rotor, disc tilt per cyclic),
`osc.js` (loop isolation), `scratch.js <free|lat|lon|ped|cruise|climb|auto|oei|ge|vrs|ground>`,
`edge.js <vne|xwind|turn>`, `audit.js`, `startup.js` (cold start and shutdown).
